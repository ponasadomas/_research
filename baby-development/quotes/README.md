# Quotes

Every quote pulled from this niche's sources: 2,970 records in 12 files, one JSON object
per line. The fields and the allowed values are in `../README.md`.

- `reddit-dr01` to `dr06`: the first reading, October 2026 (1,624 quotes).
- `reddit-ur01` to `ur05`: the re-reading of posts an earlier subject filter had kept out,
  2026-11-16 (1,182 quotes).
- `reviews-rv1`: app and book reviews (164 quotes).
- `merged/all.jsonl`: all of them in one file, generated; do not edit.

These files are never edited by hand. A new reading adds a new file. On 2026-11-17 the
`raw_file` value in each record was rewritten for the new folder layout; nothing else changed.
