# _work

Support files, kept as a record of how the research was done. Nothing here is needed to
read the research; the checks in `_tools/` use `reddit-selection/` and `reading-ledgers/`.

- `reddit-selection/`: which posts were picked from the shared archive and handed to readers.
- `reading-ledgers/`: per reader, every post and what came of it.
- `sources/`: the old source map and notes on data that was not collected.
- `scratchpad/`: the agents' working files.
- `old-README.md`: the study's README before the move.
- `who-she-is/`: the briefs and the three reading parts behind `evidence/who-she-is.md`.
