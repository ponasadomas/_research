# Sales letters

Old long-form sales letters sold to this buyer, recovered from the Wayback Machine.

- **Collected:** from 2026-11-03, with `_tools/history/wayback.py`.
- **Question:** is anyone selling to her, and what has worked before?
- **`overview.md`:** what counts as a sales letter, how the search was done, what was found.
- **`sales-letters.md`:** one row per capture attempt.
- **`candidates-A.tsv`, `candidates-B.tsv`, `suggested-links.csv`:** the lists the search produced.
- **`raw/`:** the captured pages, 553 files.
- **`logs/`:** the agents' briefs and run logs.
- **Not done:** the one-note-per-letter write-ups.
