# Quotes

Every quote pulled from this niche's sources: 34191 records, one JSON object per line. The
fields and the allowed values are in `../README.md`.

- `reddit-rNN.jsonl`: 25185 quotes
- `reddit-urNN.jsonl`: 8772 quotes
- `reviews-rvNN.jsonl`: 234 quotes
- `merged/all.jsonl`: all of them in one file, generated; do not edit.

Files whose name contains `ur` come from the 2026-11-16 re-reading of posts an earlier
subject filter had kept out. These files are never edited by hand; a new reading adds a new
file. On 2026-11-17 the `raw_file` value in each record was rewritten for the new folder
layout; nothing else changed.
