# Quotes

6,991 quotes in 59 files, one JSON object per line. Fields are described in
`../README.md`.

- Files whose name starts `reddit-ur` hold the 4,829 quotes from the 2026-11-17 re-reading
  of material an earlier subject filter had kept out. Despite the name they come from
  every kind of source, forums included.
- The other files are the October 2026 reading, named after the round that produced them.

These files are never edited by hand. On 2026-11-17 the `raw_file` value in each record
was rewritten for the new folder layout; nothing else changed.
